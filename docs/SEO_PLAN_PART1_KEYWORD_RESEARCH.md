## 2. Rakip Analizi

### 2.1 Typora (Ana Rakip)
```
Güçlü Yanları:
- WYSIWYG deneyimi
- Güçlü marka bilinirliği
- Cross-platform (şimdi ücretli)
- Math block desteği (KaTeX/LaTeX)
- Diagram desteği (Mermaid)

Zayıf Yanları:
- Artık ücretli (89$)
- Electron tabanlı değil
- Rakiplerin ortaya çıkmasına neden oldu

OwnMD Fırsatı:
- Ücretsiz alternatif olarak öne çıkar
- Modern Electron mimarisi
- Aynı özellikler + ekstra
```

### 2.2 Obsidian
```
Güçlü Yanları:
- Büyük topluluk
- Vault/klasör sistemi
- Eklenti ekosistemi
- Linked notes özelliği

Zayıf Yanları:
- Karmaşık arayüz (başlangıç için)
- Not alma odaklı, basit editör değil
- Ağır kaynak kullanımı

OwnMD Fırsatı:
- Basit, odaklanmış editör
- Hızlı başlangıç
- Hafif ve hızlı
```

### 2.3 MacDown
```
Güçlü Yanları:
- Ücretsiz ve açık kaynak
- Hafif
-Basit arayüz

Zayıf Yanları:
- Geliştirme durmuş gibi
- KaTeX/Mermaid yok
- Modern özellikler eksik

OwnMD Fırsatı:
- Modern alternatif
- Aktif geliştirme
- Tüm modern özellikler
```

## 3. Keyword Strateji Matrisi

### 3.1 EN (English) - Ana Dil
```
Ana Hedefler:
1. "markdown editor mac" → Açılış sayfası, Hero
2. "best markdown editor mac" → Karşılaştırma sayfası
3. "free markdown editor mac" → Fiyatlandırma/Ücretsiz sayfası
4. "markdown editor with math support" → Özellikler sayfası
5. "markdown editor with mermaid" → Özellikler sayfası

Long-tail Stratejisi:
- Her blog yazısı 1 ana keyword + 2-3 long-tail
- FAQ bölümleri için "how to", "what is" keywordları
- Tutorial içerikleri için "how to use markdown" tarzı
```
