## 1. Content Strategy Overview

### 1.1 Content Pillars (Ana İçerik Direkleri)

```
PILLAR 1: Ürün Tanıtımı
├── Ana Sayfa
├── Özellikler Sayfası
├── Karşılaştırma Sayfası
├── Fiyatlandırma/Ücretsiz Sayfası
└── Download Sayfası

PILLAR 2: Eğitim İçerikleri
├── Blog Yazıları
├── How-To Rehberleri
├── Kullanım Kılavuzları
└── Video İçerikler

PILLAR 3: Topluluk & Destek
├── Docs/Dokümantasyon
├── FAQ Sayfası
├── Forum (varsa)
└── Destek Kanalları

PILLAR 4: Araştırma & Değerlendirmeler
├── "En İyi Markdown Editörleri" Listeleri
├── Karşılaştırma Yazıları (vs Typora, vs Obsidian, vs MacDown)
├── Alternatif Listeleri
└── Kullanım Senaryoları
```

### 1.2 Content Funnel (İçerik Hunisi)

```
TOFU (Top of Funnel) - Farkındalık:
├── "Markdown Nedir?" → Yeni başlayanlar
├── "Neden Markdown Kullanmalısınız?"
├── "En İyi macOS Markdown Editörleri 2026"
└── "OwnMD vs Diğer Editörler"

MOFU (Middle of Funnel) - Değerlendirme:
├── "OwnMD Özellikleri" → Detaylı özellikler
├── "KaTeX Kullanım Rehberi" → Teknik kullanıcılar
├── "Mermaid Diyagramları Oluşturma" → Gelişmiş kullanıcılar
└── "Ücretsiz vs Ücretli Editörler"

BOFU (Bottom of Funnel) - Dönüşüm:
├── "OwnMD İndir" → Doğrudan indirme
├── "Hızlı Başlangıç Rehberi" → İlk adımlar
├── "Kurulum Talimatları" → Teknik kurulum
└── "SSS" → Son tereddütleri giderme
```

## 7. Content Kalite Standartları

### 7.1 Her İçerik İçin Gerekli Unsurlar

| Unsur | Açıklama | Zorunlu |
|-------|----------|---------|
| Unique Title | Tekil, açıklayıcı, keyword içeren | ✓ |
| Meta Description | 150-160 karakter, keyword içeren | ✓ |
| H1 | Sayfanın ana konusu | ✓ |
| Content Length | En az 300 kelime (blog: 1000+) | ✓ |
| Images | Görsel desteği (optimize edilmiş) | ✓ |
| Internal Links | İlgili sayfalara linkler | ✓ |
| External Links | Güvenilir kaynaklara linkler | △ |
| Call to Action | İndirme veya etkileşim için | ✓ |
| Schema Markup | FAQ, HowTo, Article | △ |

### 7.2 Content Scoring (İçerik Puanlaması)

```
SEO SCORE = Σ(Element Points)

Element Points:
├── Title (15 puan)
│   ├── ✓ İyi (keyword + açıklayıcı): 15
│   ├── △ Orta (açıklayıcı ama keyword yok): 8
│   └── ✗ Kötü (genel veya yok): 0
│
├── Meta Description (15 puan)
│   ├── ✓ İyi (150-160 char + keyword): 15
│   ├── △ Orta (var ama optimize değil): 8
│   └── ✗ Kötü (yok veya çok uzun/kısa): 0
│
├── H1 (10 puan)
│   ├── ✓ Tekil, keyword içeren: 10
│   ├── △ Var ama optimize değil: 5
│   └── ✗ Yok veya birden fazla: 0
│
├── Content Length (20 puan)
│   ├── ✓ Mükemmel (1000+ kelime): 20
│   ├── ✓ İyi (500-1000 kelime): 15
│   ├── △ Yeterli (300-500 kelime): 10
│   └── ✗ Yetersiz (<300 kelime): 0
│
├── Internal Linking (15 puan)
│   ├── ✓ 3+ link: 15
│   ├── △ 1-2 link: 8
│   └── ✗ Hiç link yok: 0
│
├── Images (10 puan)
│   ├── ✓ Optimized görsel + alt text: 10
│   ├── △ Var ama optimize değil: 5
│   └── ✗ Yok: 0
│
└── Schema Markup (15 puan)
    ├── ✓ Uygun schema var: 15
    └── ✗ Yok: 0

TOPLAM: 100 puan
HEDEF: 70+ puan (tüm içerikler için)
```
